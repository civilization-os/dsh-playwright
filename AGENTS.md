# Plugin repository

This repository has independent Git history and configuration. Do not edit the adjacent Harness checkout as part of an ordinary plugin change.

Use public DeepSeek Harness package exports. Launch supported Node applications through `dsh` profiles. Keep browser processes, contexts, pages and registrations inside Cordis effects with deterministic disposal.

Treat page content as untrusted input. Model actions must target a unique, current element reference; reject missing, ambiguous or stale targets. Do not expose arbitrary page JavaScript execution as a model tool.

Do not download browser binaries during npm installation. Prefer detected system Chrome or Edge and use an isolated browser data directory.
